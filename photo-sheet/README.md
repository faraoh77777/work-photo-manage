# 사진대지생성기 (work-photo-manage 전용)

작업사진 앱(work-photo-manage)에서 올린 사진을 불러와 사진대지(엑셀/PDF)를 만드는 로컬 프로그램입니다.
이 PC에서 직접 실행하는 프로그램이며, 인터넷 웹사이트가 아닙니다.

## 처음 쓰실 때 (최초 1회만)

1. 이 컴퓨터에 [Python](https://www.python.org/downloads/)이 설치되어 있어야 합니다 (3.9 이상 권장).
2. PDF로 저장하려면 이 컴퓨터에 **Microsoft Excel**이 설치되어 있어야 합니다 (엑셀 파일을 PDF로 변환할 때 사용).
3. `최초설치.bat`을 더블클릭해서 필요한 프로그램(패키지)을 설치합니다.

## 매번 쓰실 때

`사진대지_생성기_실행.bat`을 더블클릭하면 브라우저가 열리면서 사진대지생성기 화면이 뜹니다.

## 다른 회사(현장)의 사진을 불러오려면

화면 위쪽 "설정" 안에 "연결할 현장(Supabase)" 칸이 있습니다. 비워두면 기본 현장(대선이엔씨)
사진을 불러오고, 다른 회사가 만든 현장의 사진을 불러오려면 그 회사의 작업사진 앱 →
`site-setup.html`(현장 관리 화면)에서 확인한 Supabase URL/key를 여기 입력하면 됩니다.

## 카카오톡으로 받은 사진을 넣을 때 참고

"💻 PC에서 선택 불러오기" / "📄 개별 불러오기"로 카카오톡을 통해 받은 사진을 넣을 수 있습니다.
다만 카카오톡을 거치면 파일 이름이 바뀌고 사진에 담긴 부가정보(EXIF)도 사라지는 경우가 많아서,
**기기번호/작업구역/작업내용/날짜가 자동으로 채워지지 않습니다** — 사진에 찍힌 워터마크 글자를
보고 직접 입력해야 합니다. 자동으로 다 채워지길 원하시면 "☁️ 갤러리에서 불러오기"(작업사진 앱
클라우드 전송)를 사용하세요.
