처음 시작하는 분들을 위한 안내

앱을 아직 안 깔았다면 ① 앱 설치부터, 현장 관리자는 ② 새 현장 만들기부터, 직원은 ③ 사용 방법부터 보시면 됩니다.

이런 분이 보시면 됩니다 — 원스토어 등 앱 스토어에서 아직 다운로드할 수 없어서, 이 링크로 폰에 바로 설치하고 싶은 모든 분. 스토어 앱과 똑같이 아이콘이 생기고 똑같이 동작합니다.
설치 링크 https://faraoh77777.github.io/work-photo-manage/ — 이 주소를 카톡 등으로 받아서 아래 순서대로 진행하면 됩니다.
📱 안드로이드 (Chrome)
  1. 1

    받은 링크를 Chrome으로 엽니다.

  2. 2

    오른쪽 위 ⋮ (점 3개) 메뉴를 누릅니다.

  3. 3

    홈 화면에 추가 또는 앱 설치를 선택합니다.

  4. 4

    확인을 누르면 홈 화면에 아이콘이 생기고, 그 뒤로는 아이콘을 눌러 앱처럼 바로 열 수 있습니다.

  1. 1

    받은 링크를 반드시 Safari로 엽니다.

    꼭 확인하세요 카카오톡·다른 앱 안에 있는 브라우저로 열면 "홈 화면에 추가"가 안 보일 수 있습니다. 링크를 길게 눌러 "Safari로 열기"를 선택하거나, Safari 앱에 직접 주소를 입력해서 여세요.
  2. 2

    화면 하단(또는 상단) 공유 버튼 (□ 위로 화살표)를 누릅니다.

  3. 3

    아래로 스크롤해서 홈 화면에 추가를 선택합니다.

  4. 4

    오른쪽 위 추가를 누르면 홈 화면에 아이콘이 생깁니다.

자주 묻는 질문
스토어에서 받은 앱이랑 뭐가 다른가요?
화면과 기능은 완전히 동일합니다. 스토어 심사를 기다릴 필요 없이 이 링크만 있으면 누구나 바로 설치해서 쓸 수 있다는 점만 다릅니다.
"홈 화면에 추가" 메뉴가 안 보여요.
카카오톡 등 다른 앱 안에 열린 내장 브라우저일 가능성이 높습니다. 오른쪽 위 "···" 또는 공유 메뉴에서 "다른 브라우저로 열기"(또는 "Safari로 열기")를 선택한 뒤 다시 시도해 주세요.
설치한 뒤 현장 연결은 어떻게 하나요?
바로 옆 "② 새 현장" 또는 "③ 사용법" 탭을 참고하세요. 관리자에게 받은 초대 링크를 열면 자동으로 연결됩니다.
이런 분이 보시면 됩니다 — 우리 회사만의 독립된 공간에서, 사진·회원 정보가 다른 회사와 절대 섞이지 않게 쓰고 싶은 관리자. 무료로 만들 수 있고, 한 번 설정해두면 이후 직원들은 링크 하나로 바로 연결됩니다.
준비 · 설정
  1. 1

    로그인 화면에서 "새 현장 만들기" 열기

    앱을 열고 로그인 화면 맨 아래 다른 회사/현장 관리자이신가요? 새 현장 만들기를 누릅니다.

  2. 2

    Supabase에 무료 프로젝트 만들기

    사진과 회원 정보를 저장할 우리 회사만의 저장공간입니다. Supabase 새 프로젝트 만들기 열기 버튼으로 이동해 가입하고, 프로젝트를 하나 새로 만듭니다.

    가입은 구글 계정으로 이메일을 새로 만들 필요 없이 "Continue with Google" 버튼으로 평소 쓰는 구글 계정으로 바로 가입하는 게 가장 빠르고 간편합니다.
    알아두면 좋아요 작은 현장 규모라면 무료 사용량 안에서 충분히 운영됩니다. 프로젝트 이름은 회사명으로 지어두면 나중에 알아보기 쉽습니다.
  3. 3

    주소(URL)와 key 값을 복사해서 붙여넣기

    Supabase 프로젝트의 Project Settings → API에서 Project URL과 anon / publishable key를 찾아, 앱 화면의 두 입력칸에 각각 붙여넣습니다. 현장 이름도 자유롭게 적어주세요.

  4. 4

    설정 SQL 실행하기

    설정 SQL 복사하기를 누른 뒤, SQL Editor 열기로 이동해 붙여넣고 Run을 누릅니다. 사진·회원·설정을 저장할 표(테이블)를 한 번에 만들어주는 스크립트입니다.

    이 단계만 조금 낯설 수 있어요 그냥 복사 → 붙여넣기 → 실행, 딱 세 번만 누르면 됩니다. 실수해도 다시 실행하면 되니 걱정하지 마세요.
  5. 5

    연결 확인하고 시작하기

    연결 확인하고 이 현장으로 시작하기를 누르면 자동으로 회원가입 화면으로 이동합니다. 여기서 본인 정보로 가입하면, 이 현장을 처음 만든 사람으로 인식되어 자동으로 운영자가 됩니다(승인 절차 없이 바로 이용 가능).

  6. 6

    직원 초대하기

    운영자로 로그인한 뒤 "현장 관리" 화면의 직원 초대 링크에서 초대 링크 만들기를 누르면 링크와 QR코드가 생깁니다. 이걸 카톡으로 보내거나 QR을 보여주면, 직원 폰에서 Supabase 정보를 몰라도 자동으로 우리 현장에 연결됩니다.

    • 초대받은 직원이 가입하면 운영자 승인을 한 번 거쳐야 로그인됩니다(관리자 화면에서 승인).
    • 초대 링크는 몇 번이고 다시 만들어 나눠줄 수 있습니다.
자주 묻는 질문
비용이 드나요?
Supabase 무료 요금제 범위 안에서는 비용이 들지 않습니다. 현장 규모가 아주 커지면 그때 유료 전환을 고려하시면 됩니다.
기존 회사(대선이엔씨) 데이터와 섞이나요?
아니요. 새 현장을 만드는 순간부터 사진·회원·설정이 완전히 별도의 저장공간에 쌓입니다. 서로 전혀 보이지 않습니다.
다른 컴퓨터나 다른 사람 폰에서도 관리자 화면을 쓰고 싶어요.
그 기기에서도 같은 초대 링크(또는 URL/key)로 한 번만 연결하면 됩니다. 연결 정보는 각 기기(브라우저)에 저장됩니다.
이런 분이 보시면 됩니다 — 매일 현장에서 사진을 찍고 기록을 남기는 모든 직원. 가입부터 첫 사진 전송까지, 실제로 걸리는 시간은 3분 정도입니다.
시작하기
  1. 1

    가입하기

    관리자에게 받은 초대 링크(또는 QR)를 열면 우리 현장에 자동으로 연결됩니다. 회원가입 탭에서 회사명·이름·전화번호·비밀번호(4자리 숫자)와 담당 업무를 입력하고 가입합니다.

    가입 직후 바로 쓸 수 있는 게 아니라 관리자 승인을 한 번 거쳐야 합니다. 승인되면 그때부터 로그인이 됩니다.
  2. 2

    로그인하기

    전화번호와 4자리 비밀번호로 로그인합니다. 처음 로그인할 때는 사용할 비밀번호를 화면에서 직접 한 번 정하게 됩니다 — 그 뒤로는 계속 같은 번호를 씁니다.

  3. 3

    사진 찍기

    촬영 화면에서 기기번호·작업분류·작업구역·특이사항을 입력하고 촬영하면, 입력한 정보가 사진에 자동으로 찍혀서(워터마크) 저장됩니다. 같은 조건으로 여러 장 이어 찍을 수 있습니다.

  4. 4

    전송하기

    다 찍었으면 아래 두 가지 방법 중 골라서 보냅니다.

    전송하기

    회사 서버(클라우드)로 올라가서 팀 전체가 갤러리에서 확인할 수 있습니다. 특별한 사정이 없으면 이 버튼을 씁니다.

    카톡으로 전송

    서버엔 안 올라가고, 내 카카오톡으로 바로 공유됩니다. 특정 담당자에게 개인적으로 빠르게 보낼 때 씁니다.

알아두면 좋은 것들
비밀번호를 잊어버렸어요.
관리자에게 요청해 계정을 초기화(비밀번호 재설정) 받으면, 다음 로그인 때 새 비밀번호를 다시 정할 수 있습니다.
계정 없이 그냥 사진만 빨리 찍고 싶어요.
로그인 화면 아래 "계정 없이 사진만 찍고 카톡으로 보내기"로 들어가면, 가입 없이 촬영과 카톡 전송만 바로 쓸 수 있습니다. 다만 이 경우 회사 서버에는 저장되지 않습니다.
저는 관리자인데, 갤러리 확인이나 사진대지 만들기는 어디서 하나요?
로그인 후 계정 메뉴의 "관리자 화면"에서 사진·일보 갤러리, 인원 승인, 현장 설정 등을 모두 관리할 수 있습니다. (관리자·운영자 권한 계정에만 보입니다)
이런 분이 보시면 됩니다 — 직원들이 보낸 사진을 모아 확인·정리하고, 사진대지(엑셀/PDF 보고서)까지 만들어야 하는 관리자·운영자.
폰에서도 됩니다 관리자·운영자 계정으로 로그인하면 앱 계정 메뉴에 "관리자 화면"이 자동으로 뜹니다. 회원 승인과 사진 확인·분류는 PC 없이 폰에서도 그대로 처리할 수 있습니다. (아래 "PC 저장" 기능과 사진대지생성기만 PC 전용입니다)
회원 승인
  1. 1

    가입 신청 확인하기

    관리자 화면 맨 위 회원 승인 대기 카드에 새로 가입한 사람이 자동으로 뜹니다. 이름·전화번호·소속 회사/프로젝트·희망 역할이 같이 표시됩니다.

  2. 2

    승인 또는 거부하기

    맞는 사람이면 승인, 잘못 가입했거나 모르는 사람이면 거부를 누릅니다. 승인해야만 그 사람이 로그인해서 앱을 쓸 수 있습니다.

    권한 확인하고 누르세요 희망 역할이 관리자·운영자인 사람을 승인하면 이 관리자 화면과 사진 갤러리까지 전체 권한이 그대로 넘어갑니다. 확인 창에 역할이 표시되니 꼭 읽고 승인하세요.
사진관리(갤러리)
  1. 1

    갤러리 열기

    관리자 화면에서 사진/일보 갤러리 열기를 누릅니다. 크롬(또는 네이버 웨일 등) 브라우저에서 여는 걸 권장합니다.

  2. 2

    동기화로 사진 받아오기

    상단 동기화 버튼을 누르면 직원들이 보낸 사진을 받아옵니다.

    꼭 확인하세요 기간을 기본값(최근 30일)으로 두면 오래된 사진은 안 받아집니다. 처음 여는 기기라면 기간을 "전체 기간"으로 바꾸고 동기화하세요.
  3. 3

    사진 확인하고 분류 다듬기

    왼쪽 목록에서 작업분류별로 모아볼 수 있고, 날짜·기기번호·팀명으로 검색·필터할 수 있습니다. 기기번호가 비어있는 사진은 자동 분류로 워터마크 글자를 읽어 한 번에 채운 뒤, 한 장씩 확인하고 저장하면 됩니다.

  4. 4

    PC에 정리해서 저장하기

    상단 선택으로 저장할 사진들을 고른 뒤 PC 저장을 누르면, 사진마다 작업분류를 확인하고 폴더별로 나눠서 내 컴퓨터에 저장할 수 있습니다. (처음 한 번은 저장할 폴더를 지정해야 합니다)

사진대지생성기
  1. 1

    실행하기

    회사 컴퓨터에서 사진대지_생성기_실행.bat을 더블클릭하면 브라우저가 열리며 화면이 뜹니다. (처음 딱 한 번만 최초설치.bat을 먼저 실행)

  2. 2

    기본 정보와 저장 폴더 설정

    상단 설정에서 공사명·회사명·사진관리 구분을 입력하고, 저장 폴더에서 폴더 지정으로 완성 파일이 저장될 위치를 정합니다. 한 번 정하면 다음부터 다시 안 물어봅니다.

  3. 3

    사진 불러오기

    상황에 맞게 고릅니다.

    • 갤러리에서 불러오기 — 직원이 보낸 사진 중 원하는 걸 골라 자동으로 기기번호·구역·날짜가 채워진 페이지로 만듭니다.
    • PC에서 선택 불러오기 — 이미 내 컴퓨터에 있는 사진들을 골라 같은 방식으로 묶습니다.
    • 개별 불러오기 — 사진 한 장 한 장을 서로 다른 페이지로 따로 넣습니다.
  4. 4

    페이지 내용 다듬기

    각 페이지의 도면번호·위치·작업내용·날짜를 확인하고 필요하면 고칩니다. 레이아웃은 사진 2장(세로)/4장(2×2) 중 고를 수 있습니다.

  5. 5

    파일 이름 정하고 다운로드

    맨 아래 파일 이름 칸에 원하는 이름을 직접 입력한 뒤(비워두면 자동으로 지어줍니다) 엑셀 다운로드 또는 PDF 다운로드를 누르면, 위에서 지정한 폴더에 바로 저장됩니다.
